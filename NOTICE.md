## Contenido de terceros

Las guías, textos, imágenes, listas de herramientas y piezas se obtienen bajo demanda desde la API pública de iFixit (https://www.ifixit.com/api/2.0). Pertenecen a sus autores y a la comunidad de iFixit y se publican bajo la licencia Creative Commons Reconocimiento–NoComercial–CompartirIgual 3.0 (CC BY-NC-SA 3.0): https://creativecommons.org/licenses/by-nc-sa/3.0/

Cada guía mostrada enlaza a su versión original e indica su autor cuando la API lo entrega. Esta aplicación solo modifica la presentación (diseño, etiquetas, orden de bloques); no altera el contenido de los pasos.

## Condiciones

- Uso no comercial.
- Mantener esta atribución y la indicación de cambios.
- Distribuir las adaptaciones bajo la misma licencia.
- No usar este contenido para entrenar sistemas de IA sin licencia de iFixit.
- Para uso comercial, solicitar autorización directamente a iFixit.

## Seguridad

Reparar dispositivos electrónicos implica riesgos (baterías de ion de litio, cristal roto, herramientas afiladas). Sigue siempre las advertencias de cada guía. Los autores de esta interfaz no se responsabilizan por daños derivados de una reparación.
